# العالمية ERP/POS — Al-Alamiya ERP/POS

نظام إدارة تخطيط الموارد ونقاط البيع (ERP & Point-of-Sale) مخصص لمعارض ومحلات الأثاث والمفروشات في مصر، مبني بنواة عربية (Arabic RTL First).

دستور وقواعد المشروع الحاكمة موثقة في [AGENTS.md](file:///d:/elalamya-main/AGENTS.md).

---

## حالة المشروع: المرحلة 1 — الأساس الهندسي والتشغيلي (Phase 1 Foundation) ✅

تم الانتهاء بنجاح من **المرحلة 1 (الأساس فقط)** لتهيئة بنية تحتية نظيفة، متينة، وقابلة للتوسع وفق أعلى المعايير الهندسية ودستور المشروع:
- ✅ **الخلفية (Laravel 11 / PHP 8.2)**: توثيق وتوجيه نسخي `/api/v1`، توثيق Sanctum، نظام استجابات وأخطاء موحد، فصول القيمة المالية الثابتة `Money` والكميات الصحيحة `Quantity`.
- ✅ **الصلاحيات والأدوار**: دور المالك (`owner`) ودور الكاشير (`cashier`) مع حماية خادمية صارمة عبر Middleware و Laravel Gates تمنع الكاشير من دخول التقارير الحساسة والإعدادات.
- ✅ **الواجهة الأمامية (React 19 / TypeScript / Vite)**: نظام تصميم عربي RTL عالي الكثافة والتباين، خط Cairo، عميل API مركزي يعالج الرموز ورسائل الأخطاء، وحماية المسارات (`Guards`).
- ✅ **التوثيق وجودة الكود**: اجتياز كامل لجميع اختبارات PHPUnit (22 اختبار)، واختبارات Vitest (5 اختبارات)، وفحص التنسيق Pint، وفحص الجودة Oxlint دون أي أخطاء أو تحذيرات.

> **تنبيه دستوري**: لم يتم تنفيذ وحدات الأعمال التشغيلية (المنتجات، فواتير المبيعات، المخزون، الحسابات، المرتجعات، الباركود، إلخ) في هذه المرحلة، التزاماً بحدود نطاق المرحلة 1.

## دليل البدء السريع (Quickstart)

### 1. تشغيل الخادم الخلفي (Backend)
```bash
cd backend
php artisan test              # تشغيل اختبارات الأساس
php artisan migrate --seed    # تهيئة الجداول والمستخدمين الافتراضيين
php artisan serve             # تشغيل الخادم على http://localhost:8000
```

### 2. تشغيل الواجهة الأمامية (Frontend)
```bash
cd frontend
npm test                      # تشغيل اختبارات الواجهة
npm run build                 # فحص التجميع والأنماط
npm run dev                   # تشغيل خادم التطوير على http://localhost:5173
```

### بيانات الدخول الافتراضية
- **المالك (Owner)**: `owner` / `password123` (صلاحيات كاملة تشمل التقارير والإعدادات)
- **الكاشير (Cashier)**: `cashier` / `password123` (صلاحيات تشغيلية فقط، محجوب عن التقارير)
