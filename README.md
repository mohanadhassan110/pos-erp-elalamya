# العالمية ERP/POS — Al-Alamiya ERP/POS

نظام شامل ومتكامل لإدارة تخطيط الموارد ونقاط البيع (ERP & Point-of-Sale) مخصص لمعارض وتجارة المفروشات المنزلية والأثاث الراقي، مبني بنواة عربية أصلية بالكامل (Arabic RTL-First) وفق أعلى المعايير المعمارية والمحاسبية.

دستور وقواعد المشروع الحاكمة موثقة في [AGENTS.md](file:///d:/elalamya-main/AGENTS.md).

---

## الميزات والوحدات المكتملة حتى المرحلة 12 (Phases 1 — 12) ✅

1. **الأساس المعماري والصلاحيات (Auth & Roles)**:
   - تقسيم الصلاحيات الصارم بين **المالك (`owner`)** و**الكاشير (`cashier`)** مع حظر الكاشير عن التقارير الحساسة على مستوى الـ Backend والـ Frontend.
   - عمليات مالية بدقة حسابية ثابتة غير عائمة (`fixed-precision decimal`) عبر كائن القيمة `Money`، وكميات صحيحة `Quantity`.

2. **الكتالوج والمنتجات والباركود (Catalog & Products)**:
   - إدارة الفئات والمنتجات بتسعير جملة وقطاعي وتكلفة الشراء الحالية.
   - توليد تسلسلي حتمي لرموز الباركود وفق معيار Code 128 (`[A-Z]\d{4}`).

3. **حركات المخزون والمشتريات (Inventory & Stock Receiving)**:
   - دفتر أستاذ حركات المخزون (`inventory_movements`) كمرجع تاريخي إلزامي لكل حركة.
   - استلام البضائع من الموردين وتحديث التكلفة والمخزون وحسابات الموردين ذرياً داخل DB Transaction.
   - منع المخزون السالب مطلقاً.

4. **دفاتر أستاذ العملاء والموردين (Customer & Supplier Ledgers)**:
   - تتبع كامل للمديونيات، المقبوضات، المدفوعات، وحسابات الائتمان، مع استقلالية تامة بين حركة الحسابات والمخزون.

5. **نقطة البيع وفواتير المبيعات (POS Sales & Invoices)**:
   - مبيعات قطاعي (كاشير سريع ومجهول اختياري) ومبيعات جملة مرتبطة بحساب العميل.
   - تجميد لقطة تاريخية للتكلفة (`historical unit cost snapshot`) والربح لحظة إصدار الفاتورة لمنع تشويه الأرباح عند تغير أسعار الشراء لاحقاً.
   - دعم المنتجات الخارجية (`إضافة منتج خارجي`) مع ربط تكلفة الشراء تلقائياً بمصروف مع الاحتفاظ بسريتها التامة أمام العميل.
   - حماية ضد الإرسال المزدوج باستخدام `idempotency_key`.

6. **مرتجعات المبيعات والاستبدال (Sales Returns & Exchanges)**:
   - ربط كامل بالفاتورة الأصلية والتحقق من الكميات المؤهلة.
   - خيارات متعددة: استرداد نقدي، تسوية حساب، أو استبدال بصنف آخر أعلى أو مساوٍ للقيمة.

7. **المصروفات التشغيلية (Operating Expenses)**:
   - تصنيف المصروفات، دعم ربط التكاليف الخارجية، وفصلها المحاسبي الدقيق.

8. **التقارير المالية والتحليلية (Financial Reports - Owner Only)**:
   - لوحة تقارير شاملة للمالك: إجمالي المبيعات، تكلفة البضاعة المباعة (COGS)، مجمل وصافي الأرباح، تقييم المخزون الحي، حركة طرق الدفع، وأرصدة العملاء والموردين، مع فلاتر زمنية دقيقة.

9. **طباعة الباركود والفواتير (Barcode & Invoice Printing)**:
   - طباعة فواتير رسمية بحجم **A4** وإيصالات حرارية **80 مم** مع استخراج الأرصدة السابقة والنهائية التاريخية لعملاء الجملة.
   - سرية تامة: حجب تكاليف الشراء وهوامش الأرباح وعلامات المنتجات الخارجية عن مستندات العملاء نهائياً.
   - توليد باركود Code 128 (Subset B) رسومي متجه (SVG) مع الالتزام التام بفحص الأنماط وخانة التحقق modulo-103 وحد أقصى لدفعة الطباعة (1,000 ملصق).

## حزمة التقنيات المستخدمة (Tech Stack)

- **الواجهة الخلفية (Backend)**: Laravel 11 (PHP 8.2+), MySQL / SQLite for Testing, Laravel Sanctum, BCMath.
- **الواجهة الأمامية (Frontend)**: React 19, TypeScript, Vite, Vanilla CSS Design System (RTL & Cairo Font), Lucide Icons.
- **جودة الكود والاختبارات**: PHPUnit / Pest (154 اختبار ناجح بنسبة 100%)، Vitest (55 اختبار ناجح بنسبة 100%)، Laravel Pint، Oxlint.

## دليل البدء السريع (Quickstart)

### 1. إعداد وتشغيل الخادم الخلفي (Backend)
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan test               # تشغيل حزمة الاختبارات (154 اختبار)
php artisan serve              # تشغيل الخادم على http://localhost:8000
```

### 2. إعداد وتشغيل الواجهة الأمامية (Frontend)
```bash
cd frontend
npm install
npm test                       # تشغيل اختبارات الواجهة (55 اختبار)
npm run build                  # فحص البناء والإنتاج
npm run dev                    # تشغيل خادم التطوير على http://localhost:5173
```

### بيانات الدخول الافتراضية
- **المالك (Owner)**: `owner` / `password123` (صلاحيات كاملة تشمل التقارير الحساسة)
- **الكاشير (Cashier)**: `cashier` / `password123` (صلاحيات تشغيلية كاملة، محجوب عن شاشات وتقارير الأرباح)
