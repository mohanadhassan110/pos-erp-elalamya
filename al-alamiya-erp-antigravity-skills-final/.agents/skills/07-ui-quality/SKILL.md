# UI Quality

Use Impeccable for visual design guidance and auditing where available.

Before implementation:
- define product truth and user roles
- define information hierarchy
- define spacing/type/color tokens
- define interaction states
- define RTL rules
- define POS-specific keyboard and focus behavior

After implementation:
- audit hierarchy, spacing, typography, contrast, responsive behavior and interaction feedback
- remove AI-generated visual clichés
- verify empty/loading/error/success states
- verify keyboard navigation and focus visibility
- verify print styles separately from screen UI

Do not add visual effects merely because they are possible.
